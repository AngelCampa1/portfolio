The decision

Tenant isolation between clubs was enforced at the edge instead of inside EF Core. The usual answer for a multi-tenant app is a global query filter, HasQueryFilter, that scopes every query to the caller’s tenant automatically. A filter that silently fails to apply, because a query used raw SQL or bypassed the entity, leaks data with no signal to catch it.

Instead, a single globally registered MVC action filter, ClubIdValidationFilter, compared the route’s {clubId} against the caller’s JWT claim before any of the 65 controllers’ handlers ran, and logged a cross-tenant attempt as a security event rather than letting it fall through to an empty result set. Authorization policies and composite (ClubId, …) unique constraints backed it up as defense in depth.

The tradeoff: it protected every route that carried {clubId} in the path, and did nothing for a query that forgot to filter internally: the class of bug a query filter would have caught and this design did not.

Architecture

A .NET 9 API in four backend projects with inward-pointing dependencies served three clients: a Next.js 15 web app on Cloudflare Workers, a React Native mobile app, and background jobs. The API talked to PostgreSQL, Redis, Stripe Connect, and Resend, and streamed live updates over three SignalR hubs.

The database itself changed mid-project. GatherGrove ran on SQL Server for its first nine months and cut over to PostgreSQL on 2026-02-17. The type mismatches surfaced in a day. The semantic difference (PostgreSQL’s timestamptz rejecting a DateTime with an Unspecified Kind, which SQL Server had accepted silently) took five weeks to fully surface and thread DateTimeKind.Utc through six services.

A second claims bug sat next to the tenant-isolation one: ten analytics and engagement endpoints hard-403’d on every call, because UnlimitedTierRequirementHandler read a sub or userId claim the login token never carried, only ClaimTypes.NameIdentifier. A working version of the same check existed two directories over and backed a differently named policy. The bug denied access it should have granted rather than the other way around: a broken feature, not a leak.
