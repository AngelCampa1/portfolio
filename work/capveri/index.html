The decision

CapVeri’s reconciliation engine was ported from Python to TypeScript, and the Python was not deleted. It stayed in the repository, was never deployed, and was kept under continuous test as a reference implementation the shipped TypeScript engine was checked against. Twenty-one property-based Hypothesis suites generated inputs across the money math and asserted that the two engines agreed on a tenant’s bill to the penny.

The written mandate governing the practice stated the limit in one sentence: “Matching the Python oracle is NOT automatically correct, AND diverging from it is NOT automatically a bug.” Each disagreement between the two engines had to be adjudicated against lease language and accounting practice rather than resolved by symmetry, with the ruling recorded at the call site.

That discipline cut both ways. Five places were found where the TypeScript deliberately disagreed with the Python reference, and one where it did not: a Stripe subscription-status mapper defaulted unrecognized statuses to "active" access, and the Python reference carried the identical bug, so the two engines agreed and both were wrong.

A separate hardening pass through the same money-parsing code found that a Unicode minus sign (U+2212), used in place of an ASCII hyphen in some source figures, was dropped by the amount parser instead of read as a negative sign, turning a credit into a charge. The fix widened the parser’s negative-sign handling to cover the Unicode minus alongside a bare - and parenthesis notation.

Architecture

Four independently deployed Cloudflare Workers ran in front of a single Supabase Postgres database, with no origin server and no containers anywhere in the request path. capveri-app served a React 19 SPA and reverse-proxied /api/* to capveri-api, a Hono Worker holding 43 route modules, a queue producer and consumer, and two Durable Objects.

capveri-marketing was a separate Next.js site built with OpenNext, 275 MDX pages deep. Reconciliation and lease extraction ran as jobs on five typed Cloudflare Queues, two of them backed by dead-letter queues, rather than inside a request/response cycle.
