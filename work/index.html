A skill, and the harness testing it

One skill routes a decision to a single procedure depending on what's actually hard about it, judged against a token-matched placebo so a result has to beat filler, not just beat nothing. A Python evaluation harness runs beside it, built to find out whether any of that helps rather than to prove that it does: negative results get published with the same weight as positive ones, and a prediction has to be committed before the run it's checked against, enforced by the commit graph rather than a checkbox someone ticks. Nothing here carries a verdict yet.
