The skill is a directory copied into a coding agent’s skills folder. The harness beside it is a Python CLI, de, run from my own machine. Nothing about it is hosted, and the status of every claim below lives in the repository rather than here.

The decision

The project promises two pre-registration mechanisms and has only ever run one. The mechanism that runs is a dated prediction committed to notebook/ before a result exists; de check’s provenance step reads the commit graph itself, refusing to publish a run whose README names no prediction, or whose prediction was committed after the run it explains. The second mechanism, a hash-locked refusal built for a future confirm-tier run, checks that a skill’s text and its analysis script both still match what was pre-registered before it will start, and aborts with a diff if either has changed since. It carries a full branch-coverage floor and has never been called, because no confirmation run has happened yet. Rather than let an untested gate sit quietly and look tested, pyproject.toml declares it by name as unwired, with the exact condition that would wire it in, and the build refuses to pass if that declaration is removed while the module stays uncalled, or kept once it stops being true.

Architecture

The skill is one entry point that reads what’s hard about a decision, such as too much unranked context, advice that might not fit the person, or consequences that fork downstream, and routes to a single procedure suited to that shape rather than running every procedure on every question. A placebo file, matched to the real procedures on length and structure but built to sound helpful without implementing any of their procedures, ships in the same directory as the real ones, because a skill that only beats nothing has not been measured against the thing that would fake it. Three arenas separate iteration from evidence: dev and screen may change the skill freely and never emit a verdict; confirm targets a private holdout and does emit one; code enforces the split rather than discipline. The harness’s own README states, ahead of any result, that the corpus behind every trigger number published so far was largely solvable by a rule that just counts how long a turn is: not a footnote added later, but sitting on the front page, in the same document that makes the claims it undercuts.

The current status lives in SCORECARD.md and docs/STATUS.md, not here, because it changes.

Experimental design
Four arms share the same items in every comparison: off (control), on (treatment), placebo (token- and structure-matched filler), and cot (plain 'think step by step'), plus a fifth in-situ arm that injects the skill on top of the default system prompt instead of replacing it
