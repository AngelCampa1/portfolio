The decision

Every availability answer GeoLeap gave cost money: the data came from one commercial API billed per call. Two budget-check systems ended up in the codebase, and the one wired into the request path was the weaker of the two.

BudgetManager, the better-designed one, checked a per-provider limit as well as daily and monthly totals, but it had exactly one caller, an admin reporting endpoint, so nothing on the request path ever consulted it. ApiCostManager was the one in the call path, and it capped spend at $200 a month and $10 a day, a smaller set of numbers than the $500, $20 and $300 the config file separately declared. The two were never reconciled, so the honest statement of the ceiling is the smaller pair.

Both checks that did run failed open on a database or cache error, returning true from the catch block under a comment explaining the choice: the wrong default for a per-call-billed dependency, but a documented one rather than an oversight.

Architecture

Three clients (a Next.js 16 web app, a React Native mobile app, and a Playwright end-to-end suite) sat in front of one .NET 9 API of 68 controllers and 905 HTTP endpoints, backed by PostgreSQL, Redis, Stripe, and a single paid streaming-availability API.

Like GatherGrove, the schema itself changed mid-project: 202 entities were squashed into a single PostgreSQL baseline migration when the project cut over from SQL Server in February 2026.
